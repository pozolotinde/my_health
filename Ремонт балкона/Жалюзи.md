# Мастер-паспорт: тепловая завеса остекления балкона (зима)

## 1. Роль
Специалист-теплотехник и строитель.

## 2. Задача
Найти и отранжировать наиболее эффективные решения (или их комбинацию) для зимней теплозащиты остекления балкона.

**Цели:**
1. Устранить конденсат.
2. Снизить теплопотери через остекление.
3. Устранить микросквозняки.
4. Поддерживать **+20…+22 °C** на балконе при закрытой двери в комнату.
5. Учесть летний режим (мобильный кондиционер, перегрев).

**Ограничение:** работа в рамках задачи.
**Выход:** сводная таблица отранжированных решений.

## 3. Исходные данные

| Параметр | Значение |
|---|---|
| Ориентация | Юго-восток |
| Геометрия балкона | Длина 2,96 м, ширина 0,8 м, высота 2,40 м |
| Остекление | Одинарное, профиль неизвестен. Начинается с 0,84 м от пола, подоконник 6 см |
| Уличная сторона | Раздвижное, ≈ 2,96 × 1,56 = 4,6 м² |

| Пол (снизу вверх) | Плита → перлитобетон 8–10 см → ЭППС 20 мм → ЭППС с покрытием 10 мм → кабель тёплого пола → плиточный клей → керамогранит |

| Связь с комнатой | Дверь или окно, закрываются |

| Климат | Юг России. Лето: в среднем +30 °C, максимум +45 °C. Зима: в среднем 0 °C, минимум −15 °C |
| Лето | Мобильный кондиционер |
| Бюджет | Без ограничений |

## 4. Решения (договорённости)

| № | Решение |
|---|---|
| Р1 | Уличная и западная стороны закрываются на сезон глухо, проветривание через створки зимой не нужно |
| Р2 | Восточный торец утепляется стационарно по стеклу под шкаф |
| Р3 | С остеклением работаем только текстилем и карнизами. Исключения: восток и съёмная сезонная плёнка на стекло |
| Р4 | Тёплый пол проектируется заново, мощность можно поднять. Конвектор — резерв |
| Р5 | Источники влаги возможны (сушка белья), но в морозные дни бельё на балконе не сушится |
| Р6 | Свет зимой не критичен |
| Р7 | Высоту шторы или экрана выбирает специалист по эффективности: от потолка до подоконника |
| Р8 | Летний режим учитывается в оценке решений |

## 5. Ключевые расчётные выводы

1. **Теплопотери без мер.** Одинарное стекло имеет U ≈ 5,8 Вт/м²·К. При площади ≈ 5,6–5,85 м² (без востока) потери с инфильтрацией составляют ≈ 0,8–0,9 кВт при 0 °C и ≈ 1,4–1,5 кВт при −15 °C. Через парапет дополнительно уходит ≈ 40 / 70 Вт.
2. **Предел тёплого пола.** Его ограничивает температура поверхности (≤ 29–31 °C), а не мощность кабеля. Полезная отдача ≈ 90–110 Вт/м², то есть ≈ 200–250 Вт на ≈ 1,95 м².
   - Рекомендация: установленная мощность 200–220 Вт/м² (≈ 400–450 Вт), датчик пола с ограничением 30 °C.
   - Шаг 6 см ускоряет прогрев, но не увеличивает отдачу.
3. **Конденсат.** При одинарном стекле его не устранить полностью. При −15 °C стекло ≈ −5 °C, а точка росы ≈ +10 °C (+21 °C, 50 %).
   - Задача — перенести зону конденсации за герметичный тёплый слой.
   - Правило: **внутренний слой плотнее наружного**. Наружное остекление не герметизировать, его неплотности проветривают зазор.
4. **Штора без периметрального уплотнения (верх, бока, низ) вредна.** Она охлаждает стекло и создаёт конвективную петлю, конденсат усиливается.
5. **Штора до пола не нужна.** Парапет утеплён, а такая штора отрезает полосу тёплого пола. Оптимально перекрывать от потолка до подоконника с прижимом к нему.

## 7. Восточный торец (под шкаф)

| Ранг | Решение | Комментарий |
|---|---|---|
| 1 | Панель PIR или ЭППС 30–50 мм, фольга к стеклу, вставка в раму на уплотнитель без сплошной приклейки, зазор 5–10 мм | Нет термонапряжений и плесени. Задняя стенка шкафа отступает от панели на 3–5 см |

| ✗ | Тёмный материал, сплошь приклеенный к стеклу | Риск термотрещины стекла на солнце и плесени |

## 8. Обязательные условия для любого варианта

1. Влажность зимой ≤ 45–50 %, контроль гигрометром с памятью min/max. В мороз бельё на балконе не сушить.
2. Герметичность тёплого слоя: верх, бока, низ. Внешнее остекление не герметизировать.
3. Конвектор 1–1,5 кВт с термостатом ставить в помещении перед шторой или экраном.
4. Тёплый пол: ≈ 400–450 Вт установленной мощности, ограничение пола 30 °C, без кабеля в зоне шкафа.
